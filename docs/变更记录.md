## 一、用途与管理原则

1. 记录需求、业务规则、架构、技术计划和验收条件为什么改变。
2. 只保存一份当前有效的 `docs/项目总计划书.md`，历史决策在本文件追踪；正式业务规则以 `docs/需求与业务规则.md` 为准。
3. **已确认 ≠ 已写入所有项目文件 ≠ 已实现 ≠ 已验收**。不得提前标记数据库、API、测试或部署已完成。
4. 有新规则覆盖旧规则时，保留旧决策的历史并标注“已被覆盖”，不能把相互冲突的两条都当成有效要求。
5. 后续启用 Git 后，用提交历史记录代码和文档修改；重大业务变化继续新增 CHG，单纯润色无需新增编号。
6. 第一版优先完成单体后端与真实业务闭环，Redis、微服务、云原生、AI/Agent 等按需扩展。

### CHG-002｜限制同学期同课程重复选课

- **日期**：2026-11-20
- **类型**：需求 / 业务规则 / 设计调整
- **修改前**：仅用 `UNIQUE(student_id, section_id)` 防止重复选择相同班级，不能阻止同课程不同班重复。
- **最终决策或当时决策**：同一学生在同一学期对同一课程最多只有一个有效报名/选课目标；不同班级也不能同时选择。合法退课或撤回后可按规则重新申请。报名并发也要满足该约束。
- **原因**：保证课程业务含义与并发一致性，避免学生同时选中同课程多个班。
- **影响**：选课 Service、报名校验、事务锁、SQL、并发测试；保留同班重复唯一约束。
- **验收重点**：并发申请同课两个不同班，不能同时持有两笔有效申请或选课。
- **状态**：已确认；旧即时占容量实现思路已被权重分轮录取替代

- **类型**：需求 / 业务规则 / 设计调整

- **修改前**：已发布成绩原则上不能直接修改，缺少必要纠错渠道。

- **原因**：控制正式成绩纠错权限并确保可追溯。
- **影响**：成绩更正申请、管理员授权、成绩历史、权限。

### CHG-014｜更正执行成功后新成绩立即生效

- **日期**：2026-11-20
- **类型**：需求 / 业务规则 / 设计调整
- **修改前**：可能将获批更正再次进入普通成绩审核等待。
- **最终决策或当时决策**：教师在管理员批准的范围和期限内成功执行后，改正的正式成绩立即生效，不再启动额外 72 小时审核。
- **原因**：让受控更正及时反映而不重复审核。
- **影响**：正式成绩版本、统计/GPA/排名同步更新。
- **验收重点**：授权执行成功立即生效，单纯批准不改变正式分数。

### CHG-015｜普通成绩审核期定为 72 小时

- **日期**：2026-11-20
- **类型**：需求 / 业务规则 / 设计调整
- **修改前**：首次录齐成绩后的教师复核期原拟为 7 天。
- **最终决策或当时决策**：首次全部结果记录完成后自动开始连续 **3×24 小时（72 小时）**审核期；审核期内合法修正不重启计时；到期自动按开课班级统一发布。
- **原因**：兼顾教师核对效率与学生成绩查询及时性。
- **影响**：定时发布、审核期、成绩状态和测试。
- **验收重点**：不因修改或重复任务重置首次审核起点；未到期学生不能见本轮结果。
- **状态**：已确认；待实施

### CHG-016｜更正申请期间学生只看到原正式成绩

- **日期**：2026-11-20

- **影响**：学生成绩查询、权限与缓存一致性。
- **验收重点**：更正待审/获批未执行不改变学生可见成绩。

### CHG-018｜成绩普通录入截止默认在第 20 周结束后 14 天

- **类型**：需求 / 业务规则 / 设计调整

## 五、仍需在设计阶段澄清的实施边界（不是擅自确认的新增需求）

1. 每次报名可投入的权重点数是否合法支持 0、最小单位是否只允许整数、可否修改已提交的投入：设计接口前需要给出校验规则。
2. 在待开班状态中，如何明确区分“本轮已录取但待开班”和“仍未确定名额”，如何在最后取消时原子退回权重。
3. 第一轮结算是否立即检查开班下限与发送补选资格通知；不得违背已经确认的“达到最低人数即可确认开班、末轮仍不足则取消”。
4. 补选时点若出现超额申请，必须保证已结算的名额不被后轮更高权重者挤走。
5. 开课班级容量经管理员修改后，最低人数随之变化，哪些状态允许修改、如何避免与已有报名/待开班竞争冲突。
6. “某班首次上课后7天”计时的起点与边界，以及具体每天开放的起止小时，需在时间设计中写清。
7. 特殊考试冻结名单后才确定资格的复杂例外、特殊考试批次作废重建等，不在首版已确认范围内，不能默认为已支持。
8. 首版已明确**不做重修和先修校验**；未来若启用，重新确认 GPA、修读历史和资格条件，不得强行套用当前未定义规则。
